# 트러블슈팅 및 남은 작업

## 1. 해결한 주요 이슈

| 이슈 | 원인 | 조치 |
| --- | --- | --- |
| 커뮤니티 게시글 등록 404 | `region` 테이블이 비어 있어 `/regions/1/questions`가 지역 없음으로 실패 | `RegionSchemaMigration`에 권역 기본 seed 추가 |
| 최종 장소 노출 위험 | 지도 API에 내부 장소 속성이 섞일 수 있음 | 사용자 응답은 `publicMarkerType`만 사용하도록 분리 |
| 외부 API 키 누락 | 로컬/운영 환경에서 키가 없을 수 있음 | 키 누락 시 명확한 오류 코드 반환 |
| 비활성 계정 접근 | JWT만 있으면 비활성 계정이 접근할 위험 | JWT 필터와 Resolver에서 active 상태 확인 |
| 개발용 도착 판정 운영 노출 | devMode가 운영에서 켜질 수 있음 | backend/frontend 양쪽 환경변수로 분리 |
| OAuth 로그인 미연동 | 일반 로그인만 있어 소셜 진입이 제한됨 | Google/Kakao OAuth callback과 소셜 계정 연결 구현 |

## 3. 남은 리스크

| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 실제 현장 좌표 오차 | 도착 판정 실패 가능 | 현장 실측 후 반경 조정 |
| 외부 API 할당량 제한 | 관리자 후보 조회 실패 | 캐싱, 재시도, 운영 키 모니터링 |
| 모바일 브라우저 권한 | 위치 권한 거부 시 플레이 지연 | 안내 문구와 대체 흐름 제공 |
| 대용량 프론트 번들 | 초기 로딩 증가 | 추후 route-level code splitting |

## 4. 향후 개선 과제

- OAuth 운영 도메인/redirect URI 점검 자동화
- 실제 제휴 쿠폰 발급/사용 처리
- 관리자 대시보드 통계 강화
- 현장 인증 사진/QR 기반 도착 보조 검증
