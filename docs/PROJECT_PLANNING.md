# Operation KOREA Project Planning

Last updated: 2026-06-08

이 문서는 현재 구현 상태와 이후 확장 로드맵을 분리해 설명한다. 구현 완료 여부는 README와 `docs/MVP_STATUS.md`, `docs/REQUIREMENTS_AUDIT.md`를 우선 기준으로 한다.

## 1. 제품 방향

Operation KOREA는 TourAPI/Kakao Local 기반 장소 후보를 사건 현장으로 각색해, 사용자가 실제 장소를 이동하며 단서와 퍼즐을 풀고 최종 진실을 추리하는 모바일 야외 방탈출/사건파일 서비스다.

관광 설명 중심이 아니라 다음 경험을 중심으로 한다.

1. 사건파일 선택
2. 사건 브리핑
3. 수사 지도 확인
4. 실제 장소 방문
5. GPS 도착 판정
6. 현장 퍼즐 풀이
7. 단서/증거/용의자 카드 해금
8. 사건파일 탭에서 자료 정리
9. 최종 장소 추리
10. 제한형 최종 추리 채팅
11. 최종 정답 제출
12. 클리어 후 실제 역사 해설과 리뷰

## 2. 현재 MVP 범위

현재 MVP는 “샘플 또는 관리자 생성 에피소드 1개를 실제로 플레이할 수 있는가”를 기준으로 한다.

MVP에 포함된 것:

- 인증/JWT/현재 사용자
- 관리자 회원 관리
- episode 기반 사건파일 플레이
- 지도 전체 장소 표시
- 최종 장소 서버 내부 은닉
- 도착 판정
- 퍼즐 제출
- reward_payload 기반 단서/자료 해금
- 사건파일 탭
- 최종 추리
- 최종 정답과 CLEARED
- 클리어 리포트
- CLEARED 기준 리뷰
- 에피소드 찜/즐겨찾기: `episode_favorites`, 목록/상세 favorited, 내 관심 목록
- 일정 관리
- 팔로우/그룹
- 챌린지/랭킹
- 사용자 추천
- 플레이 코칭/분석
- 관리자 에피소드 생성/검수/공개
- TourAPI/Kakao 후보와 수동 후보 보강

MVP에 포함하지 않은 것:

- OAuth 소셜 로그인
- 실제 제휴 쿠폰/상품권 지급
- 다국어/무장애/두루누비/기상청 API

## 3. 사용자 시나리오

### 일반 사용자

1. 이메일/비밀번호로 로그인한다.
2. 공개된 사건파일 에피소드를 선택한다.
3. 브리핑에서 사건 개요와 최종 질문을 확인한다.
4. 지도에서 전체 조사 장소를 확인한다.
5. Tmap으로 장소까지 이동한다.
6. GPS 또는 시연용 devMode로 도착 판정을 받는다.
7. 현장 퍼즐을 풀고 보상 단서를 얻는다.
8. 사건파일 탭에서 용의자, 증거, 메모, 사진 카드가 해금되는지 확인한다.
9. 최종 후보 장소 중 실제 최종 장소를 추리해 방문한다.
10. 최종 추리 채팅에서 제한형 질문을 한다.
11. 최종 정답을 제출한다.
12. 클리어 리포트와 실제 역사 해설을 확인한다.
13. 리뷰를 작성한다.

### 관리자

1. 관리자 계정으로 로그인한다.
2. `/admin/episodes`에서 TourAPI 기준 장소를 조회한다.
3. 기준 장소를 선택한다. 이 장소는 서버 내부 최종 장소가 된다.
4. Kakao Local로 주변 후보지를 조회한다.
5. 후보가 부족하면 수동 후보를 추가한다.
6. 8~9개 장소로 초안을 구성한다.
7. 규칙 기반 또는 Gemini 초안을 생성한다.
8. 퍼즐, 정답, 힌트, reward_payload, 용의자, 증거를 검수/수정한다.
9. DRAFT로 저장한다.
10. readiness를 확인한다.
11. 부족 항목을 수정한다.
12. PUBLISHED로 전환한다.
13. 일반 사용자 화면에서 노출과 플레이 진입을 확인한다.

## 4. 확장 로드맵

### P0: 운영 안정화

- 실제 모바일 Kakao Map 표시 확인
- 실제 모바일 Tmap 길찾기 확인
- 현장 GPS 도착 반경 검증
- 후보 장소 좌표/접근성/운영시간/현장 관찰 요소 검수
- AI 생성 문제 관리자 검수 프로세스 고정

### P1: 플레이 품질 고도화

- Gemini 기반 최종 추리 고도화
- 최종 추리 답변 품질 평가
- 클리어 시간 기반 점수 보정
- 관리자 PUBLISHED 전 현장 검수 체크리스트 UI

### P2: 사용자 확장 기능

- 일정 관리 고도화: 팀 일정, 알림, 캘린더 연동
- 그룹 고도화: 초대, 그룹 일정, 그룹 랭킹
- 챌린지 고도화: 기간제 챌린지, 보상, 관리자 운영 UI
- 사용자 추천 고도화: Gemini 기반 개인화 설명 생성
- AI 코칭 고도화: 클리어 리포트 기반 LLM 피드백

### P3: 관광/지자체 확장

- 실제 제휴 쿠폰/상품권/지역화폐 연계
- 다국어 TourAPI
- 무장애 관광정보 API
- 두루누비 걷기여행 코스 API
- 기상청 단기예보 API
- 지자체 운영 대시보드

## 5. 발표/제출 시 표현 주의

- 일정, 팔로우, 그룹, 챌린지, 랭킹, 사용자 추천, 코칭은 MVP 구현 상태다. 다만 추천/코칭은 현재 LLM 호출이 아니라 설명 가능한 규칙 기반이다.
- 지역 리워드는 placeholder이며 실제 쿠폰 지급 기능이 아니다.
- Gemini 생성은 관리자 검수 전제의 초안 생성 구조다.
- 실제 현장 정보는 운영 공개 전 현장 검수가 필요하다.
- `/map` 응답에서 실제 최종 장소가 노출되지 않는 것이 핵심 보안/게임 규칙이다.
- 현재 완성된 핵심은 “사건파일형 야외 방탈출 1개 에피소드 플레이 MVP”다.
