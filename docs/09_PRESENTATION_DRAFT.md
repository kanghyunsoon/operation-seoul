# 발표 원고

## 1. 제목

Operation KOREA  
실제 장소 기반 미션 메모형 야외 방탈출 서비스

## 2. 문제

관광 서비스는 보통 장소 정보만 보여준다.
이 프로젝트에서는 사용자가 장소를 직접 찾아가고, 관찰하고, 퍼즐을 풀면서 기억에 남는 경험을 만들고자 했다.

## 3. 서비스 흐름

로그인 → 에피소드 선택 → 브리핑 → 지도 이동 → 도착 판정 → 퍼즐 풀이 → 단서 해금 → 최종 추리 → 정답 제출 → 클리어 리포트

## 4. 사용 기술

- Vue 3, Vite
- Spring Boot, Spring Security, MyBatis
- MySQL
- Kakao Map, Tmap
- TourAPI, Kakao Local
- OpenAI/Gemini

## 5. 핵심 기능

- 실제 장소 기반 에피소드 플레이
- GPS/devMode 도착 판정
- 퍼즐과 미니게임
- 사건 파일과 단서 해금
- 최종 추리와 정답 제출
- 리뷰, 커뮤니티, 피드, 랭킹, 챌린지
- 관리자 에피소드 제작과 AI 초안

## 6. 보안/게임 규칙

최종 장소나 정답이 미리 보이면 게임이 깨지기 때문에 지도 응답에서 내부 필드를 빼고, 프론트는 공개 마커만 사용하게 했다.
미니게임도 클라이언트 결과만 믿지 않고 서버에서 proof를 다시 확인한다.

## 7. 관리자 기능

관리자는 장소 후보를 조회하고, AI 초안을 만들고, 에피소드의 장소/퍼즐/증거/용의자를 수정할 수 있다. 공개 전에는 readiness 검사로 빠진 데이터가 없는지 확인한다.

## 8. 결과

핵심 플레이 흐름은 끝까지 연결됐다.
추가로 커뮤니티, 피드, 랭킹, 챌린지, 코칭까지 넣어서 플레이 이후에도 사용할 수 있는 구조로 만들었다.

## 9. 남은 점

실제 운영을 하려면 현장 검수, OAuth 운영 도메인 등록, Tmap/GPS 실기기 확인, 제휴 쿠폰 지급 연동이 더 필요하다.

## 10. 마무리

Operation KOREA는 관광지를 단순히 보는 것이 아니라 직접 플레이하는 공간으로 바꾸는 프로젝트다. MVP 기준으로는 에피소드 제작부터 플레이, 클리어, 리뷰까지 흐름을 구현했다.
