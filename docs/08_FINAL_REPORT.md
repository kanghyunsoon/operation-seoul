# 최종 보고서

작성일: 2026-06-25

## 1. 프로젝트 개요

Operation KOREA는 실제 장소를 기반으로 한 모바일 야외 방탈출/미션 파일 서비스다. 사용자는 권역별 미션을 선택하고, 실제 장소를 이동하며 퍼즐을 풀고 단서를 해금한 뒤 최종 추리를 통해 사건을 해결한다.

## 2. 프로젝트 목표 달성 여부

| 목표 | 달성 여부 | 설명 |
| --- | --- | --- |
| 도메인 기반 서비스 기획/설계/구현 | 달성 | 장소 기반 미션 파일 서비스로 기획 및 구현 |
| 요구사항→설계→구현→검증 경험 | 달성 | 요구사항 문서, 설계 문서, 구현 결과, 트러블슈팅 정리 |
| Spring Boot REST API + Vue SPA 연동 | 달성 | 백엔드 API와 Vue Axios 클라이언트 연동 |
| MySQL · MyBatis 기반 DB 구조 | 달성 | `schema.sql`, MyBatis repository |
| 외부 API · 생성형 AI 활용 | 달성 | TourAPI, Kakao, Tmap, Gemini 활용 |
| Git 기반 협업 경험 | 달성 | 기능별 파일/문서 분리, 최종 산출물 정리 |

## 3. 핵심 기능

- 회원가입/로그인/JWT 인증.
- 권역 기반 에피소드 목록 조회.
- 미션 브리핑, 지도, 장소 도착 판정.
- 퍼즐 풀이와 단서/증거/용의자 해금.
- 최종 추리와 최종 정답 제출.
- 클리어 리포트와 리뷰.
- 찜, 팔로우, 일정, 그룹, 챌린지, 랭킹.
- 관리자 회원/리뷰/에피소드 관리.
- 외부 장소 API와 Gemini 기반 에피소드 초안 생성.

## 4. 구현 결과

Back-End는 Spring Boot, Spring Security, JWT, MyBatis, MySQL 기반으로 구성했다. Front-End는 Vue 3, Pinia, Vue Router, Axios 기반 SPA로 구현했다.

현재 구현률은 전체 약 82%로 평가한다. 필수 기능은 대부분 충족했으며, 추가 기능과 심화 기능도 MVP 수준으로 구현되어 있다.

## 5. 미흡한 점

- 사용자 추천/코칭은 생성형 AI보다는 규칙 기반 분석에 가깝다.
- 에피소드 목록 화면의 하단 UI 간격은 추가 polish가 필요하다.
- 실제 GPS 도착 판정과 장소 접근성은 현장 검증이 필요하다.
- 프론트 자동 테스트가 부족하다.

## 6. 향후 개선 방향

1. 에피소드 목록 반응형 UI 안정화.
2. 사용자 검색/정렬 기능 강화.
3. Gemini 기반 개인화 추천/코칭 문장 생성.
4. 관리자 챌린지/콘텐츠 운영 UI 고도화.
5. 실기기 GPS/Kakao Map/Tmap 검증.
6. E2E 테스트와 배포 체크리스트 구축.

## 7. 결론

Operation KOREA는 Final 프로젝트 요구사항의 핵심인 CRUD, 회원, 리뷰, 추가 기능, AI/외부 API 활용, Spring Boot + Vue + MySQL/MyBatis 연동을 충족한다. 실서비스 전에는 UI 안정화와 운영 검증이 필요하지만, 발표와 시연 가능한 완성도 있는 MVP로 평가할 수 있다.
