# 최종 보고서

## 1. 프로젝트명

Operation KOREA: 실제 장소 기반 미션 메모형 야외 방탈출 서비스

## 2. 개발 배경

기존 관광 앱은 장소 소개와 길찾기 중심이라 사용자의 몰입과 재방문 동기가 약하다. 본 프로젝트는 실제 장소를 사건의 단서 공간으로 재해석해, 사용자가 이동하면서 퍼즐과 추리를 해결하는 플레이 경험을 제공한다.

## 3. 목표

- 실제 장소 기반 에피소드 플레이 구현
- 지도, GPS, 퍼즐, 단서, 최종 추리를 하나의 흐름으로 연결
- 관리자용 에피소드 관리/검수 도구 제공
- 외부 API를 안전하게 활용
- 커뮤니티, 리뷰, 랭킹, 챌린지으로 서비스 확장성 확보

## 4. 구현 결과

Back-End는 Spring Boot, Spring Security, JWT, MyBatis, MySQL 기반으로 구성했다. Front-End는 Vue 3, Pinia, Vue Router, Axios 기반으로 구현했다. DB는 사용자, 에피소드, 장소, 퍼즐, 단서, 리뷰, 커뮤니티, 랭킹, 챌린지, 관리자 운영 데이터를 포함한다.

핵심 플레이 흐름은 로그인, 에피소드 선택, 브리핑, 지도 이동, 도착 판정, 퍼즐 풀이, 단서 해금, 최종 추리, 클리어 리포트까지 연결되어 있다. 관리자 기능은 장소 후보 조회, 검증, DRAFT 저장, 공개 준비도 확인, PUBLISHED 전환을 포함한다.

## 5. 기술적 특징

- 최종 장소 은닉을 위해 사용자 지도 응답에서 내부 판정 필드를 제거했다.
- `reward_payload` 구조로 퍼즐 보상과 단서 해금을 유연하게 처리했다.
- 커뮤니티 권역 기본 데이터를 마이그레이션에서 보장해 빈 DB에서도 작성 흐름이 동작한다.
- Google/Kakao OAuth 로그인과 일반 로그인을 함께 지원한다.

## 6. 검증 결과

- Backend compile 통과
- Frontend production build 통과
- 커뮤니티 게시글 등록 스모크 테스트 통과
- 핵심 서비스 단위 테스트 파일 구성

## 7. 한계

- OAuth 로그인은 구현되어 있으나 운영 배포 시 Google/Kakao 콘솔의 redirect URI와 허용 도메인 설정 검증이 필요하다.
- 실제 쿠폰 지급은 구조만 준비했고 운영 로직은 미구현이다.
- GPS 도착 판정은 실제 현장/기기 테스트가 필요하다.
