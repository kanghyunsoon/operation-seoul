# 최종 보고서

## 1. 프로젝트

Operation KOREA는 실제 장소를 배경으로 한 미션 메모형 야외 방탈출 서비스다.

## 2. 만든 이유

단순히 관광지 정보를 보여주는 것보다, 사용자가 직접 장소를 찾아가고 관찰하면서 기억에 남는 경험을 만들고 싶었다. 그래서 지도 이동, 퍼즐, 단서 수집, 최종 추리를 하나의 흐름으로 묶었다.

## 3. 구현한 내용

- 이메일 로그인과 Google/Kakao OAuth
- JWT 기반 인증/인가
- 에피소드 목록, 상세, 브리핑
- 지도 기반 장소 이동과 도착 판정
- 퍼즐/미니게임과 서버 검증
- 사건 파일, 단서, 증거, 용의자 해금
- 최종 추리 질문, 가설, 정답 제출
- 클리어 리포트, 리뷰, 댓글
- 지역 커뮤니티, 피드, 팔로우
- 추천, 랭킹, 챌린지, 코칭
- 관리자 회원/리뷰/에피소드 관리
- TourAPI/Kakao/AI를 이용한 에피소드 초안 기능

## 4. 신경 쓴 부분

가장 신경 쓴 부분은 최종 장소와 정답이 너무 빨리 노출되지 않게 하는 것이었다.
사용자 지도 응답에는 내부 최종 장소 필드를 넣지 않았고, 프론트도 공개 마커만 보고 화면을 그리게 했다.

퍼즐 미니게임도 프론트 결과만 믿지 않고 서버에서 proof를 다시 검증하도록 했다.

## 5. 아쉬운 점

- 실제 제휴 쿠폰 지급은 아직 연결하지 못했다.
- 장소는 실제 운영 전에 현장 검수가 필요하다.
- GPS와 Tmap은 모바일 실기기 확인이 더 필요하다.
- 예전 관광 미션 코드가 일부 남아 있어서 나중에 정리하면 좋다.

## 6. 다음에 하면 좋은 것

- 실제 장소 현장 검수 프로세스 만들기
- 쿠폰/제휴 보상 지급 연결
- AI 초안 품질 평가 자동화
- 플레이 로그 기반 추천 고도화
