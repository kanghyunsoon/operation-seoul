# 요구사항 정의서

본 문서는 Operation KOREA 프로젝트의 요구사항 정의서다. 상세 구현 추적표와 인수 조건은 `01_REQUIREMENTS_AND_COVERAGE.md`에 함께 관리한다.

## 1. 프로젝트 개요

Operation KOREA은 실제 지역 장소를 기반으로 사용자가 미션 파일을 선택하고, 지도 이동, 현장 도착 판정, 퍼즐 풀이, 단서 해금, 최종 추리를 진행하는 모바일 중심 야외 방탈출/미션 서비스다.

## 2. 사용자 유형

| 사용자 | 설명 | 주요 권한 |
| --- | --- | --- |
| 비회원 | 서비스 진입 전 사용자 | 일반 로그인, Google/Kakao OAuth 로그인, 회원가입 |
| 일반 사용자 | 미션 플레이 사용자 | 에피소드 플레이, 리뷰, 커뮤니티, 랭킹 |
| 관리자 | 서비스 운영자 | 회원/리뷰/에피소드 관리, 공개 준비도 점검 |

## 3. 핵심 기능 요구사항

| ID | 요구사항 | 수용 기준 | 상태 |
| --- | --- | --- | --- |
| FR-01 | 일반/OAuth 인증 | JWT 발급, Google/Kakao 로그인 가능 | 완료 |
| FR-02 | 사용자 관리 | 프로필, 비밀번호, 탈퇴, 팔로우 가능 | 완료 |
| FR-03 | 에피소드 검색/필터 | 키워드, 지역, 시대 조건 검색 가능 | 완료 |
| FR-04 | 지도 기반 플레이 | 조사 장소 표시, 최종 장소 조건부 공개 | 완료 |
| FR-05 | 현장 도착 판정 | GPS 또는 개발 모드로 도착 처리 | 완료 |
| FR-06 | 퍼즐/미니게임 | 정답 또는 미니게임 결과 제출 | 완료 |
| FR-07 | 단서/증거 해금 | `reward_payload` 기반 사건 파일 갱신 | 완료 |
| FR-08 | 최종 추리 | 질문/가설/최종 정답 제출 가능 | 완료 |
| FR-09 | 리뷰/커뮤니티 | 리뷰, 게시글, 댓글, 좋아요 가능 | 완료 |
| FR-10 | 랭킹/챌린지 | 플레이 기록 기반 부가 기능 제공 | 완료 |
| FR-11 | 관리자 운영 | 회원, 리뷰, 에피소드 관리 가능 | 완료 |

## 4. 비기능 요구사항

| ID | 요구사항 | 구현 기준 | 상태 |
| --- | --- | --- | --- |
| NFR-01 | 보안 | JWT 인증, 관리자 권한 분리 | 완료 |
| NFR-02 | 비밀값 관리 | OAuth/API 키 환경변수 또는 local properties 주입 | 완료 |
| NFR-03 | 데이터 은닉 | 최종 장소/정답 조기 노출 방지 | 완료 |
| NFR-04 | 무결성 | publish readiness로 공개 전 검증 | 완료 |
| NFR-05 | 모바일 사용성 | 반응형 UI, 하단 내비게이션, 지도 중심 UI | 완료 |
| NFR-06 | 가독성 | 버튼 대비, 상태 색상, 굵기, 포커스 보강 | 완료 |

## 5. 인수 조건

| 시나리오 | 인수 조건 |
| --- | --- |
| 로그인 | 일반/OAuth 로그인 후 보호 화면 접근 가능 |
| 플레이 | 브리핑 → 지도 → 도착 → 퍼즐 → 단서 해금 흐름 가능 |
| 최종 추리 | 조사 조건 충족 후 최종 추리와 클리어 가능 |
| 관리자 공개 | DRAFT가 공개 준비도 검증을 통과해야 PUBLISHED 전환 |
