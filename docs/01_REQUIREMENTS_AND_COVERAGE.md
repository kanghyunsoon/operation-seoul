# 요구사항 정의서 및 구현 추적표

## 1. 프로젝트 개요

Operation KOREA은 실제 지역 장소를 기반으로 사용자가 미션 파일을 선택하고, 지도 이동, 현장 도착 판정, 퍼즐 풀이, 단서 해금, 최종 추리를 진행하는 모바일 중심 야외 방탈출/미션 서비스다. 관리자는 외부 장소 API를 활용해 에피소드를 검수하고 공개한다.

## 2. 프로젝트 목표

| 구분 | 내용 |
| --- | --- |
| 서비스 목표 | 실제 장소 탐방과 추리형 미니게임을 결합한 지역 기반 미션 경험 제공 |
| 운영 목표 | 관리자가 에피소드, 장소, 퍼즐, 단서, 리뷰, 회원을 웹에서 관리 |
| 검증 목표 | 공개 전 검증 단계로 최종 정답, 단서, 증거, 지도 노출 오류 방지 |

## 3. 사용자 유형

| 사용자 | 설명 | 주요 권한 |
| --- | --- | --- |
| 비회원 | 서비스 진입 전 사용자 | 일반 로그인, Google/Kakao OAuth 로그인, 회원가입 |
| 일반 사용자 | 미션을 플레이하는 사용자 | 에피소드 플레이, 리뷰, 커뮤니티, 랭킹 |
| 관리자 | 서비스 운영자 | 회원/리뷰/에피소드 관리, 공개 준비도 점검 |

## 9. 인수 조건

| 시나리오 | 인수 조건 |
| --- | --- |
| 사용자 로그인 | 일반/OAuth 로그인 후 JWT가 저장되고 보호 화면으로 이동한다. |
| 에피소드 플레이 | 브리핑 후 지도 화면에서 조사 장소를 선택하고 도착 판정 후 퍼즐을 풀 수 있다. |
| 단서 해금 | 퍼즐 정답 후 보상 단서와 사건 파일 데이터가 갱신된다. |
| 최종 추리 | 조건 충족 전 최종 장소가 숨겨지고, 조건 충족 후 최종 추리로 이동한다. |
| 리뷰 작성 | 클리어한 사용자만 리뷰를 작성할 수 있다. |
| 관리자 공개 | DRAFT 에피소드가 publish readiness를 통과해야 PUBLISHED 전환된다. |

## 10. 제한 및 남은 위험

- 실제 현장 GPS 정확도는 기기/브라우저/도심 환경에 따라 추가 검증이 필요하다.
- GitHub 등 외부 이미지 URL은 공개 Raw 이미지 URL이어야 브라우저에서 정상 표시된다.
- 대용량 프론트엔드 번들 경고는 기능에는 영향이 없지만 추후 code splitting으로 개선 가능하다.
