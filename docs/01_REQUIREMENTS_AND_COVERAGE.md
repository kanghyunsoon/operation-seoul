# 요구사항 정의서 및 구현 추적표

## 1. 프로젝트 개요

Operation Seoul은 실제 지역 장소를 기반으로 사용자가 미션 파일을 선택하고, 지도 이동, 현장 도착 판정, 퍼즐 풀이, 단서 해금, 최종 추리를 진행하는 모바일 중심 야외 방탈출/미션 메모 서비스다. 관리자는 외부 장소 API와 생성형 AI를 활용해 에피소드 초안을 만들고, 검수 후 공개한다.

## 2. 사용자 유형

| 사용자 | 설명 |
| --- | --- |
| 비회원 | 로그인/회원가입 화면 접근 |
| 일반 사용자 | 에피소드 플레이, 리뷰, 커뮤니티, 랭킹, 추천, 코칭 이용 |
| 관리자 | 회원/리뷰/에피소드 운영, AI 초안 생성, 공개 준비도 점검 |

## 4. 비기능 요구사항

| ID | 요구사항 | 구현 기준 | 상태 |

| NFR-06 | 장애 대응 | 외부 API 키 누락/할당량 초과 시 명확한 오류 반환 | 완료 |

## 5. 제외/제한 범위

- OAuth 소셜 로그인은 최종 범위에서 제외했다.
- 쿠폰/제휴 리워드는 DB 구조만 준비했고 실제 지급 로직은 구현하지 않았다.
- Gemini 실시간 자유 대화 추리는 운영 안정성을 위해 제한형/검수형 구조로 유지했다.
- GPS 도착 판정은 실제 현장/실기기 검증이 추가로 필요하다.
